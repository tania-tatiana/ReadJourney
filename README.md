# 📚 ReadJourney

**ReadJourney** is a web application designed to help readers organize their personal libraries, plan their reading activities, and track their reading progress.

The application allows users to discover books, add them to their personal library, record reading sessions, and monitor their reading statistics.

## ✨ Features

- **User Authentication** — create an account and log in.
- **Recommended Books** — browse a selection of recommended books.
- **Personal Library** — add books and manage their reading status.
- **Reading Progress Tracking** — record reading sessions, track completed pages, and monitor progress.
- **Reading Diary** — view reading session records and results.
- **Reading Statistics** — analyze reading time and progress.

## 🛠 Technologies

## 🚀 Getting Started

To run the project locally, follow these steps:

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd ReadJourney
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided in the terminal.

## 🔗 API

The application uses a REST API to manage user accounts, recommended books, personal libraries, and reading progress.

**API Base URL:**

`https://readjourney.b.goit.study/api`

## 📄 Application Pages

- `/` — Home page.
- `/register` — User registration.
- `/login` — User login.
- `/recommended` — Recommended books.
- `/library` — Personal library.
- `/reading/:bookId` — Book reading page and progress tracking.
